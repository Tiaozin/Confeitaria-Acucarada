# 🍰 Confeitaria Açucarada

Site desenvolvido para a **Confeitaria Açucarada** durante minha participação na Empresa Júnior do curso de Sistemas de Informação.

O projeto teve como objetivo criar uma página web para apresentar os produtos da confeitaria de forma organizada, visualmente agradável e adaptada para diferentes dispositivos.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts

## ✨ Funcionalidades

* Página inicial da confeitaria
* Menu de navegação
* Seção de ofertas
* Catálogo de produtos
* Informações de preço e descrição dos produtos
* Links para contato e redes sociais
* Layout responsivo para desktop, tablet e celular
* Rolagem horizontal de produtos em dispositivos menores
* Efeitos de interação e animações

## 📱 Responsividade

O projeto possui layouts adaptados para diferentes tamanhos de tela utilizando CSS Media Queries:

* **Desktop:** acima de 1024px
* **Tablet:** entre 601px e 1024px
* **Celular:** até 600px

## 🚀 Como executar

O projeto utiliza HTML, CSS e JavaScript puro, não sendo necessário instalar dependências.

Clone o repositório:

```bash
git clone https://github.com/Tiaozin/Confeitaria-Acucarada.git
```

Entre na pasta:

```bash
cd Confeitaria-Acucarada
```

Depois, abra o arquivo `index.html` em um navegador.

Também é possível utilizar o **Live Server** no Visual Studio Code para executar o projeto localmente.
